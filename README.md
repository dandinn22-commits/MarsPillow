# Mars Pillow — חנות אונליין

אתר חנות מלא לכרית Mars Pillow, באנגלית אמריקאית, בנוי ב־PHP ו־MySQL בלי שום התקנות נוספות. הוא מתאים לאחסון משותף של הוסטינגר.

## מה יש באתר
- **עמוד בית** עם כרית תלת־ממדית שאפשר ללחוץ עליה, פירוק לשכבות בגלילה, השוואת יישור צוואר, לוח 60 לילות, חבילות, שאלות נפוצות.
- **דף מוצר** (`/product/mars-pillow`) עם צפייה בתלת־ממד, גלריה, בחירת חבילה, כמות, לשוניות מידע וכפתור "הוסף לסל" צף בטלפון.
- **סל קניות, תשלום בכרטיס (Stripe) ובפייפאל**, עמוד תודה ועמוד ביטול תשלום.
- **אודות, שאלות נפוצות, צור קשר** (עם הגנה מספאם).
- **דפים משפטיים** לחנות בארה"ב: פרטיות, תנאי שימוש, משלוחים, החזרות, נגישות.
- **דף ניהול** (`/admin`) עם רשימת הזמנות, סימון "נשלח" ומספר מעקב, והודעות מטופס יצירת קשר.
- **מיילים** אוטומטיים: אישור הזמנה ללקוח, התראה אליך, ומייל "ההזמנה נשלחה".
- **קידום בגוגל:** כותרת ותיאור לכל עמוד, נתונים מובנים של מוצר ושאלות נפוצות, מפת אתר, קובץ robots.
- **מעקב:** Google Analytics 4 ופיקסל של מטא, שנטענים רק אחרי שהגולש מאשר עוגיות.

## מבנה התיקיות
```
private/            ← מחוץ ל-public_html. כאן הסיסמאות והקוד.
  config.example.php  תבנית הגדרות. מעתיקים ל-config.php וממלאים.
  bootstrap.php       הפעלה, אבטחה, שגיאות
  routes.php          כל הכתובות של האתר
  admin.php           דף הניהול
  src/                סל, הזמנות, Stripe, PayPal, מיילים, אבטחה, קידום
  templates/          כל העמודים, המיילים והדפים המשפטיים
  lib/PHPMailer/      שליחת מיילים דרך SMTP
  storage/            קבצי לוג (נוצרים לבד)
public_html/        ← זה מה שעולה לתיקיית האתר
  index.php, .htaccess, favicon.ico
  assets/css, assets/js, assets/img
install.sql         ← יוצר את טבלאות מסד הנתונים
tests/              ← בדיקות (לא מעלים לשרת)
design-preview/     ← תצוגת העיצוב המקורית
brand/              ← קבצי הלוגו
```

## איפה משנים דברים
| מה | איפה |
|---|---|
| מחירים, חבילות, קישורי אמזון | `private/config.php` → `offers` |
| ימי ניסיון, אחריות, זמן משלוח, אימייל, כתובת | `private/config.php` → `site` |
| שכבות הכרית, מידות, חומרים, כביסה | `private/config.php` → `product` |
| מעבר מבדיקה לאמיתי | `private/config.php` → `'mode' => 'live'` |
| שאלות נפוצות | `private/src/seo.php` → `faqs()` |
| כותרות ותיאורים לגוגל | `private/src/seo.php` → `page_meta()` |
| טקסטים בעמודים | `private/templates/pages/` |

כל מקום שכתוב בו `[TODO]` הוא פרט שחסר. במצב בדיקה הוא מופיע באתר כתווית כתומה, ובמצב אמיתי הוא מוסתר.

## מס מכירות בארה"ב
כרגע לא מחושב מס. כשתגיע לסף שמחייב גביית מס במדינה מסוימת, אפשר להפעיל את Stripe Tax: בקובץ `private/src/stripe.php` יש שורה מוכנה (`automatic_tax`) שצריך רק להוריד ממנה את סימן ההערה. שים לב שזה מחשב מס רק לתשלומים בכרטיס. לתשלומים בפייפאל צריך פתרון נפרד. מומלץ להתייעץ עם רואה חשבון אמריקאי.
